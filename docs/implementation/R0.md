## Findings that change later phases

1. **The base DenseNet has no tuberculosis or silicosis head.** Its 18 outputs
   cover pneumonia, effusion, atelectasis, edema and the like, but 2 of the 7
   conditions in the SotaRad sample (TB and silicosis, the subnet's headline
   conditions) map to nothing. R2's reference miner needs a fine-tuned head for
   them. Until then a TB campaign's seed leader would score near chance on its
   main label.
2. **rad-dino and cxr-foundation are encoders, not classifiers.** A miner using
   them must train and ship a head. That fits the solution contract
   (`load_model_checkpoint`, `map_to_labels`), but the reference miner should
   stay on DenseNet.
3. **Labels follow the spec's certainty rule plus status.** `definite` and
   `probable` count as positive and `possible` doesn't. The SotaRad export also
   marks some TB as `previous` (healed); the probe treats those as negative.
   DataHive should confirm how `previous` will appear in `/files` findings
   before R5's label adapter.
4. **Serving is permanent on production.** The DataHive probe serves nothing
   unless `--serve N` is passed, and refuses `--serve` on a host that doesn't
   look like staging or the demo unless `--i-know-this-is-production` is set.
5. **L4 capacity is not guaranteed.** One L4 request was refused outright and
   the next queued for about 7.5 minutes; L40S started at once. R6 must treat
   `ResourceExhaustedError` and queueing as infrastructure, not miner fault:
   retry or reschedule the entry, never score it as a crash. Eval timeouts must
   start when the container starts, not when `Sandbox.create` is called.
6. **Load time includes CUDA start-up.** On L40S, importing torch took 4.9 s
   and the first load 5.0 s; the L4 run had a warmer cache (0.8 s load). A
   `model_load_timeout` of 120 s leaves a wide margin for DenseNet-sized
   models, and R4 should measure it from the start of `load_model`, after
   imports.

## Running the remaining probes

```bash
uv sync --python 3.12 --extra r0 --extra r0-models --extra dev
set -a; source .env; set +a
```

From the Hetzner validator host, once staging exists:

```bash
python -m scripts.r0 datahive --serve 20 --reset-after
```

Storage, Hugging Face and the demo rerun, from anywhere with the credentials:

```bash
python -m scripts.r0 storage
python -m scripts.r0 hf
python -m scripts.r0 models --source demo
```

Each probe rewrites its file in `r0_results/`; update the table above from it.
